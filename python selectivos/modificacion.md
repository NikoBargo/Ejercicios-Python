Que condiciones se utilizo?
El if, elif y else

Porque las organizo de esta manera?
Como primero se uso el if para crear el primer bloque de la condicion donde las dos balotas eran rojas, despues se usaron el elif para el resto de condiciones 
exepto por la ultima donde se uso el else por si ninguna de las opciones anteriores se cumple.

Que ocurre si cambia uno de los valores de entrada?
Pues depende de lo ingresado las condiciones cambian y el resultado de las promociones varian.
